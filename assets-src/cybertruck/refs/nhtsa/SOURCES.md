# Real-vehicle windshield measurements

Source: NHTSA, 2024 Tesla Cybertruck Beast frontal NCAP test, test vehicle O20244500,
test date 2024-12-18. Report NCAP-KAR-24-006 / TR-P44392-01-NC.
https://nrd-static.nhtsa.dot.gov/reports/vehdb/v10000/v15300/v15312R001.pdf
Downloaded 2026-10-04. The saved PDF is an unmodified two-page excerpt, printed pages 10 and 25
(original PDF pages 14 and 29). Reference only; not shipped in the app.

- Data sheet 3, printed p.10: WA = 19.9 degrees from horizontal. The diagram confirms the angle convention.
- Data sheet 15, printed p.25: A = 1433 mm across the top, C = 1785 mm across the bottom,
  D = 1780 mm height in the windshield's own front-view plane. A and C are widths, not side lengths.
  B, E and F locate the protected zone; they are not glass edge dimensions.
- Periphery = 6778 mm, an independent check on the large pane dimensions.

These are measurements of an actual Cyberbeast. We apply pane dimensions to the AWD model because both
use the same windshield assembly. We retain the model's Medium ride height; this is not an assertion
that the test vehicle's absolute roof or bonnet heights match Medium. Top placement at apex minus 40 mm
remains photo-derived. No published trim cross-section dimension was found in these sources.
