# Heart replica: literature values

Normal adult values with sources, for the parts and motion built on top of the Rodero et al. 2021 average heart (Zenodo 4593739, end-diastole).

Conventions: values are mean ± SD unless noted. M = men, W = women. "ED" = end-diastole, "ES" = end-systole, "MS" = mid-systole. "not found" means no citable normal value was located in this pass. Rows marked **(unverified)** cite a source whose number was seen only second-hand (secondary page, search snippet, or from memory of a standard text) and was not read in the primary text this session; check before relying on it.

Short keys used in the tables (full references at the end): **Oliveira 2020**, **Henry 2022 (WASE)**, **Pouch 2014**, **KB 2020** (Kawel-Boehm SCMR 2020), etc.
