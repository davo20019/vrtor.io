# Security

Please don't report security problems in public issues. Email **hello@vrtor.io** with what you found
and how to reproduce it; you'll get a reply within a week.

In scope: the Workers in this repository (the router and waitlist in `apps/home/src`, the presence
Durable Object and its WebSocket API, the subject Workers) and anything that lets one visitor affect
another in a shared room (names, voice, avatars).
